# These exact versions are the combination we've verified working on:
#   - macOS arm64 (Apple Silicon) with python@3.11 + ffmpeg@7
#   - Docker python:3.11-slim-bookworm with apt ffmpeg 5.1
#
# CRITICAL — ffmpeg compatibility:
#   torchcodec 0.7.0 ships precompiled native libs (libtorchcodec_core{4,5,6,7})
#   linked against libavutil.{56,57,58,59} → it ONLY works with ffmpeg 4–7.
#   ffmpeg 8 (libavutil 60) silently breaks torchcodec.
#   - Mac:    install ffmpeg@7 via Homebrew (handled by setup.sh)
#   - Docker: bookworm's apt ffmpeg is 5.1 → fine
#
# Re-running `pip install -r requirements.txt` in a fresh venv on python 3.11
# should reproduce a known-good environment.
# =============================================================================
